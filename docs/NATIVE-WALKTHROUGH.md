# 原生真机走查

文字、截图与语音三项核心的真机基线（Apple Silicon、macOS 14+）。自动测试不覆盖真实权限、焦点、剪贴板、麦克风与系统按键，这些只能在这里验。
每项填「通过 / 不通过 / 跳过」和一句现象；不通过的附截图或复现步骤。正式发布相关（DMG、公证、升级）留给 [开发计划](IMPLEMENTATION-PLAN.md) 阶段 G，不在本表。

## 发版前快速走查（约 15 分钟）

## 准备

- 退出已安装的 umuo，`ps -eo pid=,comm= | grep umuo` 确认没有别的实例（两份同时在跑时后注册快捷键的那份会静默失败，测到的是另一个进程），再打开冒烟包 `apps/macos/.build/bundle-smoke/umuo.app`（`bun run verify:macos` 产出，ad-hoc 签名，首次右键「打开」）。
- 签名与已安装版本不同：「辅助功能」「屏幕录制」可能要在系统设置里重新勾选，勾完重启 umuo。
- 记录：机型 / 芯片 / macOS 版本 / 显示器数量。

## 性能测量

发布门槛（[PRD](PRD.md) §3.2、§8）用原生 **release** 包测，不用 debug 构建或冒烟包：`sh apps/macos/scripts/bundle.sh --version X.Y.Z` 产出的 `apps/macos/dist/umuo.app`。

- **内存用 `phys_footprint`**：启动后静置 12 秒，`footprint -p <pid>`（与活动监视器一致）。不要用 `ps` 的 RSS：它把共享的系统框架页重复计入，
  会把同一个进程算大几倍。语音模型加载后另记峰值与空闲卸载后的回落。
- **空闲 CPU**：静置后 `ps -o %cpu= -p <pid>` 连采 5 次。
- **测快捷键相关指标前确认只有一个实例**（见上「准备」）。
- 旧 Tauri 版的数字只是历史基线（[归档](archive/RELEASE-GATES-tauri.md)），不算原生版的验收结果。
