# 原生真机走查

在 Apple Silicon、macOS 14+ 上验证文字、截图和语音流程，重点观察权限、焦点、剪贴板、麦克风与系统按键。DMG 安装、公证和升级按 [开发计划阶段 G](../IMPLEMENTATION-PLAN.md#阶段-g-正式发布) 验收。

每项记录「通过」「不通过」或「跳过」并简述现象。遇到失败时附截图或复现步骤。

## 准备

- 退出已安装的 umuo，`ps -eo pid=,comm= | grep umuo` 确认没有别的实例（两份同时在跑时后注册快捷键的那份会静默失败，测到的是另一个进程），再打开冒烟包 `apps/macos/.build/bundle-smoke/umuo.app`（`bun run verify:macos` 产出，ad-hoc 签名，首次右键「打开」）。
- 签名与已安装版本不同：「辅助功能」「屏幕录制」可能要在系统设置里重新勾选，勾完重启 umuo。
- 记录：机型 / 芯片 / macOS 版本 / 显示器数量。

## 静态界面预览

只检查布局时，先 `bun run build`，再运行 `apps/macos/.build/debug/Umuo --preview-ui`。
它使用固定文本和内存中的假设置，不访问用户配置、Keychain 或供应商，不注册快捷键、不向其他应用写入。
默认显示设置窗；`--preview-window=panel` / `--preview-window=compose` 分别显示翻译浮窗和输入翻译窗，
`--preview-window=voice` 显示语音浮层，`--preview-voice=result` / `processing` / `model` / `error` 切语音结果、处理中、模型提示与失败状态；
`--preview-dark` 切深色，`--preview-locale=en` / `zh-TW` / `ja` 切界面语言。
此入口只验证视觉，真实焦点、剪贴板和输入交付仍按下面的真机清单验证。

## 性能测量

发布门槛（[PRD](../PRD.md) §3.2、§8）用原生 **release** 包测，不用 debug 构建或冒烟包：`sh apps/macos/scripts/bundle.sh --version X.Y.Z` 产出的 `apps/macos/dist.noindex/umuo.app`。

- **内存用 `phys_footprint`**：启动后静置 12 秒，`footprint -p <pid>`（与活动监视器一致）。不要用 `ps` 的 RSS：它把共享的系统框架页重复计入，
  会把同一个进程算大几倍。语音模型加载后另记峰值与空闲卸载后的回落。
- **空闲 CPU**：静置后 `ps -o %cpu= -p <pid>` 连采 5 次。
- **测快捷键相关指标前确认只有一个实例**（见上「准备」）。
