# umuo 产品需求文档

版本 v0.8 · 2026-11-02 · 当前产品范围；开发进度见验收清单。

本版依据用户本轮决定替代 v0.4：三项核心为文字翻译、OCR 截图翻译、语音输入后润色或翻译；
客户端免费、MIT 开源，用户自带模型，umuo 不提供 AI 网关（2026-11-02 起不再收费，取代 v0.6 的买断方案）。语音为首版核心，原地翻译保留。
v0.8 只同步现状：仓库已公开、官网只做首页与下载跳转、客户端只发 Apple Silicon（arm64）包。
旧范围及证据已归档，不再要求按竞品功能清单补齐。

## 2. 产品定位

常驻菜单栏的 macOS AI 翻译与语音表达工具，在当前工作中读懂文字、翻译截图、把说话整理成可直接使用的文字。
客户端免费使用，模型调用费用直接向自己选择的供应商支付。

### 2.1 三项核心

| 核心 | 用户任务 |
| --- | --- |
| 文字翻译 | 划词理解、输入翻译、在可编辑输入框原地翻译 |
| OCR 截图翻译 | 框选无法直接取词的区域，本地识别后翻译 |
| 语音表达 | 按快捷键说话，整理成原语言文字，或翻译成目标语言后输入 |

### 2.2 模型与凭据

通常配置一个文字供应商的 API Key 和一个当前模型即可翻译、润色；保留自定义端点和必要代理。
本地文字模型通常只需地址与模型名。API Key 存 Keychain，界面只展示配置状态。
本地语音转写不需要 API Key，但首次需下载模型；具体引擎通过兼容性和性能实验后选定。
云端转写为后续可选项，须另行验证音频接口、模型与凭据，不能假定文字聊天接口支持音频。

## 3. 首版目标

首版完成三条可独立验收的任务流程，并提供可持续更新的正式客户端。
现有文字/OCR 能力先收敛，语音新增实现；任何一条尚未验收时，不对外宣称完整首版已交付。

### 3.1 使用体验

首次配置只要求选择供应商、填 Key、选模型、验证连接；按使用场景申请系统权限。
模型未配置、未下载或权限缺失时，界面给出可执行的下一步；请求中可取消、失败可重试。

### 3.2 验收口径

三项核心按 §5 的场景验证；性能以原生 release 包测量，内存用 phys_footprint。
语音分开记录录音结束至转写完成、后处理完成、文字交付的冷/热延迟，不预先承诺未经测量的两秒指标。
测量方法见 [NATIVE-WALKTHROUGH.md](NATIVE-WALKTHROUGH.md)「性能测量」；旧 Tauri 数据仅为[历史记录](archive/RELEASE-GATES-tauri.md)。

### 3.3 非目标

首版不提供订阅、官方模型额度、充值、AI 网关、账号登录、云同步、免 Key 网页翻译通道、团队版。
不扩展其他平台，不上 Mac App Store，不做浏览器扩展、沉浸式双语阅读、跟读评测或语言学习体系。
会议录音、长音频文件转写、语音助手及工具执行不在本轮语音范围内。

## 4. 核心场景

| 场景 | 入口 | 结果 |
| --- | --- | --- |
| 读网页、文档或聊天里的外文 | 划词快捷键 | 浮窗显示译文 |
| 输入框已有中文，准备发英文 | 原地翻译快捷键 | 成功且目标未变时替换原文 |
| 手动输入或粘贴文字 | 输入翻译窗 | 译文可预览、复制 |
| 图片、视频画面、无法取词的 PDF | 截图快捷键 | OCR 原文与译文 |
| 用说话代替打字 | 语音输入 | 同语言整理后填入原输入框 |
| 用中文口述外文消息 | 语音翻译 | 目标语言表达填入原输入框 |

## 5. 功能需求

### 5.1 共同能力

自动识别源语言，允许用户选择目标语言；核心翻译入口使用一个当前文字模型。
结果保留复制、系统朗读、必要的原文修正与重试；浮窗可钉住、拖动、缩放，支持 Esc 取消和键盘操作。
模型、语言及快捷键的具体默认值沿用兼容设置，在界面收敛阶段核定，不擅自覆盖老用户键位。

### 5.2 划词翻译

AX 优先读取选区；必要时串行模拟复制，完整保存并恢复剪贴板 item 与类型，保护用户中途复制。
翻译结果在非激活浮窗流式显示；单词保留语境释义和朗读，首版不提供扩展学习词卡。
验收覆盖 Safari、备忘录、Preview、VS Code 等真实应用；对不支持取词或命中黑名单的场景明确提示。

### 5.3 输入翻译

保留输入/粘贴原文、目标语言、触发翻译、查看和复制结果的简单窗口。
收敛现有撰写窗的多模型、风格和回译等控制；交互细节在实现时围绕这条基本任务确定。

### 5.4 原地翻译

读取选区；无选区时仅在能明确读取并安全写回的可编辑输入框中处理整框。
译文成功且完整后，核验来源、目标、原文及可写性再替换。失败、取消、截断、原文或目标变化均保留原文。
语音插入与已有原文替换是两种任务，分别验证；仅比较应用 pid 不足以证明仍是原输入框。

### 5.5 OCR 截图翻译

系统框选 + Apple Vision 本地识别；用户可修正识别原文后重译。
框选取消、权限拒绝、无文字或识别失败时不启动模型翻译。首版收敛到截图翻译单一任务，不单列静默 OCR 入口。

### 5.6 多模型对比

退出现行首版范围：并发对比、排序、最佳投票与偏好统计随精简阶段下线。

### 5.7 风格与 Prompt

不提供自建 Prompt、温度、few-shot 或大量风格预设的管理界面。
内部仍维护翻译、同语言整理、语音翻译三种清楚的任务指令；润色不擅自补充事实。

### 5.8 术语与词典

多术语表管理退出本轮首版。姓名、数字、日期、否定和中英混说进入语音准确率测试；听写词典界面暂不承诺。

### 5.9 本地记录

保留最近记录、文本搜索、删除和关闭历史；首版收敛独立收藏、复杂筛选及分析。
沿用现有数据库与已发布迁移，隐藏/退出功能不删除旧用户收藏、历史或其他已保存数据。

### 5.10 用量与费用

不提供费用报表、供应商预算和超额自动切换的产品流程；模型费用由用户与供应商结算。
底层供应商响应解析与已有数据兼容按精简计划逐步处理，不为减少界面而破坏协议解析或数据库。

### 5.11 语音输入与语音翻译

语音为首版核心，主要参考 [Handy](https://github.com/cjpais/Handy)（MIT）的源码。

- 两种输出：同语言整理、翻译至目标语言；两者均保持原意，保留否定、数字、姓名、日期、金额。
- 按住快捷键录音、松开处理，Esc 取消；显示录音、转写、后处理及错误状态。默认键位与现有动作的冲突在实现时核定。
- 首先实验验证一个多语言本地引擎，再接入录音和现有文字模型；不把候选库写成已确定或已支持。
- 润色包括必要标点、去口头语/重复和处理明确的自我纠正，不生成额外论点或事实。
- 本地模式下音频在本机处理，转写文本仅按用户配置发送给文字模型供应商；“本地转写”不等同于“全流程离线”。
- 默认录音只用于当前会话，结束或取消后清理临时音频；保存录音须另行设计，不随历史默认开启。
- 录音开始捕获输出目标，提交前复核前台、焦点对象、可写性及相关文本上下文；目标变化或无法确认时展示可复制结果。
- 语音翻译失败保留转写并提供重试，不自动把源语言文本写入；不自动按 Enter 发送消息。
- 验收包含静音、噪声、中英混说、重复、自我纠正、同应用换输入框、切换应用、权限撤回、目标退出及用户中途复制。

### 5.12 免费与开源

全部功能免费，无试用、无许可证激活、无 umuo 账号；源码以 MIT 许可证开源，仓库 2026-11-02 已公开于 github.com/youming-ai/umuo。
2026-11-02 起撤销买断方案：客户端许可证/试用门控、Worker 收费与官网购买入口一并删除。

## 6. 模型与隐私

### 6.1 供应商

保留现有 BYOK 供应商及自定义端点；首版提供一个当前文字模型，不为精简而改成只支持一家。

### 6.2 配置

配置连接时验证端点与模型，提供可理解的错误；不强制配置语音供应商 Key。

### 6.3 执行

保留请求取消、超时、错误提示、长文本分片、顺序合并和截断保护。
首版收敛分场景模型、跨供应商自动切换和自动本地回落设置；现有行为与配置须在下线阶段显式迁移并回归验证。

### 6.4 凭据与配置存储

模型 Key 只进 Keychain，界面不回显明文；配置只由 Rust 读写，保留未知字段。
配置导出不含 Key。

### 6.5 请求与输出

供应商请求通过 Rust 发出；模型输入输出按数据处理，保持占位符与格式。

### 6.6 AI 网关

不建设 umuo AI 网关，不出售模型额度；请求从客户端直接到用户配置的端点。

## 7. 原生交互

### 7.1 窗口与菜单

浮窗保持非激活行为，输入与设置使用正常原生窗口。菜单围绕文字、截图、语音三条入口及历史、设置、更新、退出组织。
减少重复入口和无关个性化；保留系统朗读，朗读入口并入结果操作。

### 7.2 快捷键

核心入口可自定义、可检测冲突；新增录音按下/松开/取消语义，不能把现有连按检测等同于按住说话。
老键位兼容处理见开发计划；默认值暂不写死为竞品方案。

### 7.3 设置

围绕通用、语言与文字模型、语音模型、快捷键与权限、隐私与记录和关于收敛；实际分组在界面实现时确定。

### 7.4 首次使用

文字翻译先完成一次连接和翻译；首次使用截图或语音时再申请屏幕录制或麦克风权限。
语音首用下载模型，显示进度、取消、错误和重试，避免把模型下载放进所有用户的启动路径。

### 7.5 反馈

流式结果与错误归属当前请求；旧会话迟到结果不覆盖新任务。后台任务取消、结果保留与失败重试都有明确状态。

## 8. 非功能要求

保持 macOS 14+、仅 Apple Silicon（arm64）；原生键盘操作、VoiceOver、系统对比度与减少动态效果走查。
本地模型记录版本、体积、校验值、许可与来源；分别验证冷/热延迟、空闲内存、加载与卸载，模型资源不默认常驻。
无遥测。用户历史保存在本机；取词黑名单与敏感输入保护覆盖相应入口。

## 9. 架构与参考

以 [ARCHITECTURE.md](ARCHITECTURE.md) 的现有分层为约束：系统能力归 Swift；可复用业务与供应商请求归 Rust；FFI 只做转换和转发。
本地推理的装配与隔离方式经实验确定，保持 umuo-app/core 无平台依赖且 Linux 可编译测试。

### 9.5 参考项目

Handy 为主要语音参考；Typeless 参考语音整理/翻译交互；不承诺功能或性能相同。
复用前核对指定版本的代码与模型许可，记录版权声明。

### 9.6 服务端边界

仓库的 `site/` 是官网与 Worker。Worker 只提供官网首页，并把 `/download/macos` 与旧的 `/download/macos/appcast.xml` 302 到 GitHub Releases 的最新附件；
安装包与更新清单都在 GitHub Releases，官网不存文件。不做支付、许可证、账号系统、内容同步、模型或语音转发服务。

## 10. 许可与商业模式

完全免费、纯 BYOK：umuo 不收费，模型调用费用由用户直接付给其选择的供应商。
源码采用 MIT 许可证（2026-11-02 定案，取代 10-30 的闭源买断方案）；外部贡献按 MIT 入站即出站，不要求 CLA。
「umuo」名称与图标不随 MIT 授权，分发修改版需换名。整个仓库（含 `site/`）均为 MIT，2026-11-02 公开于 github.com/youming-ai/umuo。

## 11. 官网

文案围绕三项核心与「免费、开源、自带 Key」，删除购买、激活、试用与退款内容。官网只有首页，不再提供条款与隐私页。
仅宣称已发布能力；语音与更新的开发状态以验收清单为准。保留当前五语言结构。页眉显示 GitHub 源码链接（仓库已公开）。

## 12. 开发与发布

先收敛现有文字/OCR 范围并验证本地语音候选，再完成语音会话、文字后处理、输入交付和产品整合；
随后完成官网与正式发布验证。各阶段交付条件见 [IMPLEMENTATION-PLAN.md](IMPLEMENTATION-PLAN.md)。
客户端改动合入 main 即自动发布到 GitHub Releases（正式版、未公证），Sparkle 经同一 Release 的 appcast 更新。
真实 N → N+1 更新与 Developer ID / 公证仍待验证；没有旧 Tauri 用户，不做旧版桥接。发布流程见 [SWIFTUI-MIGRATION.md](SWIFTUI-MIGRATION.md)。
