# Open Sans

Self-hosted Open Sans v44, normal style, variable weights 400–700.
Latin and Latin Extended subsets are loaded with `font-display: swap`.
CJK characters use the system sans-serif fallback.

- Family: https://fonts.google.com/specimen/Open+Sans
- Source stylesheet: https://fonts.googleapis.com/css2?family=Open+Sans:wght@400..700&display=swap
- Files: Google Fonts `fonts.gstatic.com/s/opensans/v44/` WOFF2 subsets.
- License: SIL Open Font License 1.1; see `OFL.txt`.
- License source: https://github.com/google/fonts/blob/main/ofl/opensans/OFL.txt

The site does not request Google Fonts at runtime.
