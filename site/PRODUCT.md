# Product

<!-- impeccable:product-schema 1 -->

本文件记录 umuo.app 官网（`site/`）设计工作所需的产品事实。产品需求以根目录 `docs/PRD.md`（v0.5）为准，
实现与发布进度以 `docs/PRD-CONFORMANCE.md` 为准；两者变化时以它们为准并同步本文件。

## Platform

web

## Users

日常需要跨语言读、写、说的 macOS 用户，主要四类：

- **跨语言工作者**：工作里要读外文、写外文消息与邮件的职场人（如在日本、外企或跨境协作的中文母语者）。
- **开发者 / 技术人员**：读英文文档与 issue、写英文消息，愿意自己配置 API Key。
- **AI 重度用户**：手上已有各家模型的 API Key 或本地模型，不想再为翻译工具另付订阅。
- **留学生 / 学术用户**：读外文资料、写外文邮件与文书。

共同的任务：不离开当前应用，读懂眼前的外文，或把自己的话（打字或说话）变成可以直接发出去的外文。
官网访客在决定「要不要下载 / 购买」，首发语言为简体中文，另有繁中、英、日、韩四种。

## Product Purpose

umuo 是常驻菜单栏的 macOS AI 翻译与语音表达工具，三项核心：

| 核心 | 用户任务 |
| --- | --- |
| 文字翻译 | 划词理解、输入翻译、在可编辑输入框原地翻译 |
| OCR 截图翻译 | 框选无法直接取词的区域，本地识别后翻译 |
| 语音表达 | 按快捷键说话，整理成原语言文字，或翻译成目标语言后输入（开发中） |

用户买的是原生客户端体验，模型调用费用直接付给自己选的供应商。官网的成功标准是访客读懂这件事并下载 / 购买。

## Positioning

**译文写回原输入框。** 邻居产品（Bob、Easydict、沉浸式翻译等）主要帮人「读懂」；umuo 把读、写、说放进一个工具，
原地替换和语音翻译把结果安全地写回当前输入框——核验来源、目标、原文与可写性后才替换，失败、取消、截断或目标变化时保留原文。
买断 + 纯 BYOK（无账号、无订阅、请求不经 umuo 服务器）是第二支撑点，不是首要卖点。

## Operating Context

- 用户在 Safari、备忘录、Preview、VS Code、聊天与邮件等真实应用里工作，umuo 通过全局快捷键介入。
- 默认快捷键（可在设置修改）：划词翻译 `⌃⌃`、输入翻译 `⌥⌘A`、输入框原地替换 `⌥⌥`、截图翻译 `⌥⌘O`、语音输入按住右 `⌥`（开发中）。
- 首次使用：选供应商、填 Key、选模型、验证连接；系统权限按使用场景申请。
- 官网形态：首页一屏 + `/pricing`、`/terms`、`/privacy`、`/activate`；地址不带语言前缀，按 cookie / Accept-Language 返回对应语言。
- 下载走 Worker `/download/macos`（读 R2 最新版）；当前为未经 Apple 公证的预览版。

## Capabilities and Constraints

- 仅 macOS 14+、仅 Apple Silicon；客户端为 Swift 6 / SwiftUI / AppKit + Rust，**闭源**——官网不得写「开源 / MIT / 自行编译」。
- 定价：US$9 一次性购买客户端；**尚未开放购买**，预览版可免费下载。设备数、试用、退款与更新权益未定，不得自行填写。
- 模型：自带 API Key（GPT、Claude、Gemini 等）、本地模型或自定义端点；Key 存系统 Keychain。
- 不在范围、不得宣传为「即将推出」：订阅、umuo 账号、官方模型额度 / 充值、AI 网关、云同步、团队版、浏览器扩展、其他平台、Mac App Store。
- 语音输入与语音翻译、购买授权尚未发布，只能标「开发中」或不提。「本地转写」不等于「全流程离线」。
- 文案唯一来源 `apps/web/src/content/<locale>.ts`，五种语言结构一致；预渲染须可 hydrate；不放假下载链接。
- 字体只用自托管或系统字体，不引外部字体服务（大陆访问不稳）。
- **芯片**：仅支持 Apple Silicon（M 系列芯片），与 PRD 一致（2026-10-29 用户确认）。官网不得写支持 Intel。

## Brand Commitments

- 名称 `umuo`（小写）。Logo：蓝底、从水里探出头的小水獭（`LogoMark` 与 `public/favicon.svg` 同一张图）。
- 已定的视觉方向「对照本」及其禁用清单写在 `site/AGENTS.md`「视觉方向」一节，是用户已确认的硬约束；本文件不展开。
- 语气：直接、具体、说清边界（例如定价页明确列出「不包含」）；只宣称已发布能力。

## Evidence on Hand

- **用户确认存在、但仓库里还没有**：真实客户端截图 / 录屏、真实用户评价、性能实测数据。使用前须向用户索取原件与授权；拿到之前不得用占位或编造内容代替。
- **不可当作现行证据**：`docs/RELEASE-GATES.md` 中的安装包体积、内存、唤起速度等数字来自旧 Tauri 构建，文件自己声明「仅为历史基线」；原生客户端的发布门槛尚未实测。
- 仓库现有资产：水獭 logo（`apps/web/public/favicon.svg`）、自托管 Open Sans（`apps/web/public/fonts/open-sans/`）、首屏读 / 写 / 截图 / 说四个演示示例（`content/*.ts` 的 `hero.demo`）。
- 没有媒体报道、客户 logo、案例研究，不得编造。

## Product Principles

1. **写回比读懂更重要**：讲产品时先讲「把译文安全地放回你正在写的地方」，再讲划词与截图。
2. **只说已发布的事**：开发中的能力明确标注，未定的商业参数不填，退出范围的不暗示。
3. **边界即卖点**：无账号、无订阅、请求直连供应商——说清楚 umuo 不做什么，和说清楚它做什么一样重要。
4. **快捷键就是界面**：产品大部分时间不可见，官网用真实键位与真实前后对照来展示它。

## Accessibility & Inclusion

- 五种语言同构，中日韩使用系统字体回落；繁中、日、韩文案与简中同等对待。
- 唯一的自发动效（首屏译文逐字流式出现）须尊重 `prefers-reduced-motion`。
